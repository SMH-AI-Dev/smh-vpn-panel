# رفع اشکال — SMH Panel

## پنل باز نمی‌شود

1. سرویس: `systemctl status smhpanel` و لاگ: `journalctl -u smhpanel -n 100`
2. فایروال: `ufw status verbose` — پورت پنل باید باز باشد
3. از خود سرور تست کن: `curl -k https://127.0.0.1:<port>/api/health`
4. اگر حالت دامنه داری: DNS را چک کن `dig +short <domain>` و پورت ۸۰/۴۴۳

## کلاینت وصل می‌شود ولی اینترنت ندارد

- در Xray لاگ را ببین: `journalctl -u xray -n 100`
- در پنل: کاربر «فعال» باشد و سهمیه/انقضا تمام نباشد
- برای Reality: SNI انتخابی باید از سرور **قابل دسترس** باشد (اگر سایت مقصد از سرور تو بلاک باشد، Reality هم کار نمی‌کند). یک SNI دیگر امتحان کن.
- ساعت سرور: `timedatectl` — اختلاف ساعت زیاد، TLS/Reality را خراب می‌کند.
- دامنه/آدرس اشتباه در لینک: در «تنظیمات → آدرس عمومی سرور» آدرس درست را بگذار و لینک را دوباره کپی کن.

## لینک اشتراک در اپ دانلود نمی‌شود

- حالت بدون دامنه: گواهی خودامضاست؛ در اپ گزینهٔ «اجازهٔ گواهی نامعتبر / Allow insecure» را فعال کن یا لینک/QR مستقیم بده.
- راه بهتر: دامنه بگیر و نصب‌کننده را با `--domain` دوباره اجرا کن.

## مصرف ثبت نمی‌شود

- پورت 10085 روی localhost باید بالا باشد (بخش stats داخلی Xray)؛ نصب‌کننده آن را با کانفیگ می‌سازد.
- بعد از تغییر کانفیگ از خارج از پنل، یک بار از داشبورد Xray را ری‌استارت کن.
- توجه: شمارنده‌ها با ری‌استارت Xray صفر می‌شوند ولی پنل مقادیر تجمعی را درست نگه می‌دارد.

## WireGuard وصل نمی‌شود

- UDP ممکن است توسط ISP مسدود باشد؛ پورت دیگر امتحان کن: «تنظیمات → وایرگارد → پورت» و بعد دوباره سرویس wg را ری‌استارت کن.
- `wg show` روی سرور: آخرین Handshake باید تازه باشد.
- IP کلاینت تکراری نباشد (پنل خودکار مدیریت می‌کند).

## Xray بالا نمی‌آید

```bash
/usr/local/bin/xray run -test -config /usr/local/etc/xray/config.json
journalctl -u xray -n 50
```

اگر کانفیگ خراب است، از پنل آخرین تغییر را برگردان (حذف اینباند/کاربر مشکوک) و دوباره ذخیره کن — فایل قبلی تا زمان واکشی موفق، جایگزین نمی‌شود.

## fail2ban من را بلاک کرده

```bash
fail2ban-client status sshd
fail2ban-client set sshd unbanip <YOUR_IP>
```

اگر IP خودت را می‌دانی، از کنسول VPS (KVM) وارد شو و بالا را اجرا کن.

## گواهی تمدید نمی‌شود

```bash
/root/.acme.sh/acme.sh --list
/usr/local/sbin/smhpanel-cert-renew
```

پورت ۸۰ باید از اینترنت قابل دسترس باشد (چالش standalone).

## ری‌استارت و ریست کامل

```bash
systemctl restart smhpanel xray
# ریست تنظیمات پنل (با احتیاط): بکاپ بگیر سپس
smhpanel backup --out /root/backup.tar.gz
```

اگر همه‌چیز بهم ریخت، همان دستور نصب را دوباره اجرا کن؛ دیتابیس و تنظیمات حفظ می‌شوند.
